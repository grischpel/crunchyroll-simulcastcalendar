# Crunchyroll Simulcast Calendar

Simple browser extension for customizing the episode progress color and viewing the simulcast calendar more comfortably.

This version is installed manually without the Chrome Web Store.

## Deutsch

### Einfachste Installation ohne Chrome Web Store

1. Lade dieses Projekt als ZIP-Datei herunter oder klone es lokal.
2. Entpacke den Ordner auf deinen Computer.
3. Öffne Chrome oder Edge.
4. Gehe zu: `chrome://extensions`
5. Aktiviere **Entwicklermodus**.
6. Klicke auf **Entpackte Erweiterung laden**.
7. Wähle den Ordner aus, der `manifest.json` enthält.
8. Die Erweiterung ist jetzt installiert und aktiv.
9. Öffne die Crunchyroll-Simulcast-Kalenderseite. Die Erweiterung sollte sofort funktionieren.

## Allgemeine Hinweise

- Für Chrome, Edge und Brave funktioniert dieselbe Methode.
- Der Ordner muss das `manifest.json`-File enthalten.
- Wenn die Erweiterung nicht aktiv ist, prüfe, ob Entwickler-Modus aktiviert ist.
- Nach erfolgreicher Installation kann die Farbe der Folgenfortschrittsanzeige im Popup angepasst werden.

## Common notes

- This method works for Chrome, Edge, and Brave.
- The selected folder must contain `manifest.json`.
- If the extension does not activate, check the Developer Mode toggle.
- After installation, the episode progress color can be customized from the popup.
